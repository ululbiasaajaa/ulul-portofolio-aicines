About Me

I am a junior software engineer with a Pharmacy background and a project-first approach to learning software engineering. My academic background trained me to work systematically, pay attention to detail, and solve problems through structured analysis.

I build web and mobile applications using React, React Native, and Expo, and backend services with Node.js, Express, and FastAPI. I have worked with authentication, role-based access, REST APIs, databases, and cloud deployment.

My recent projects also involve Gemini API, RAG, vector search with PostgreSQL/pgvector, text-to-speech, FFmpeg, Docker, and cloud deployment. I am comfortable debugging across the stack and adapting to unfamiliar technologies when a project requires it.

AI Application • Fullstack Project

PodLearn — AI Podcast & Interactive Quiz Generator

End-to-end AI application that converts PDF/text learning materials into structured two-speaker podcast conversations with generated quizzes. The system combines Gemini content generation, Edge TTS, server-side FFmpeg processing, Google OAuth, and Supabase persistence.

ENGINEERING HIGHLIGHTS:

  • ✓ Document processing: Accepts PDF and text learning materials as generation input.
  • ✓ AI content generation: Gemini creates structured two-speaker podcast scripts and quizzes.
  • ✓ Multi-speaker TTS: Edge TTS generates separate voices for the podcast speakers.
  • ✓ Media processing: FFmpeg handles server-side audio processing and merging.
  • ✓ Interactive learning: Segment-by-segment playback and mid-podcast Q&A via an AI endpoint.
  • ✓ Production debugging: Railway deployment issues including TTS timeouts and Gemini API rate limits were addressed during development.
