Berlatar belakang pendidikan Farmasi, saya membawa metodologi eksakta yang ketat, pola pikir analitis, serta presisi tinggi ke dalam dunia *software engineering*. Saya meyakini bahwa baris kode yang baik harus dibangun sepresisi formula medis.

Spesialisasi saya mencakup pembangunan antarmuka web modern (React / Tailwind), aplikasi mobile Android (React Native / Expo), serta backend performa tinggi (Laravel, Node.js, FastAPI).

Fokus utama saya saat ini adalah mengintegrasikan ekosistem AI terdepan—mulai dari RAG Engine (Gemini API), pencarian berbasis vektor (pgvector), hingga penataan kontainer terisolasi menggunakan Docker.
